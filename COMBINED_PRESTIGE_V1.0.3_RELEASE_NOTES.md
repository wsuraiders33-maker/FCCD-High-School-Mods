# Combined High School + Prestige v1.0.3 — release notes

**Proposed GitHub release tag:** `combined-v1.0.3`  
**Release title:** FCCD High School + Prestige v1.0.3 Combined Mods  
**Compatibility:** Windows, clean Steam *Football Coach: College Dynasty* 1.6.5

## What's included

Eight separately installable ZIP packages:

1. Ohio Division I + Prestige v1.0.3
2. Ohio Division II + Prestige v1.0.3
3. Ohio Division III + Prestige v1.0.3
4. Ohio Division IV + Prestige v1.0.3
5. Ohio Division V + Prestige v1.0.3
6. Ohio Division VI + Prestige v1.0.3
7. Ohio Division VII + Prestige v1.0.3
8. Generic High School + Prestige v1.0.3, with Large, Medium and Small selectable profiles

**Install one combined mod at a time. These ZIPs are alternatives, not patches to stack.** Ohio variants should be used with the corresponding Ohio high-school Workshop universe.

## Gameplay

- Prestige-based roster limits (34–85 players depending on prestige)
- Prestige-adjusted scholarship offer allowances and rolling offer-slot reuse
- In-season commitments limited by expected graduating seniors
- Postseason recruiting constrained by remaining roster capacity
- Positional depth safeguards and automatic minimum-depth walk-ons
- Four-year high-school player progression without redshirts
- High-school rules: 12-minute quarters, kickoffs from the 40 and high-school touchbacks
- Attendance, stadium and neutral-site calibration for the selected Ohio division or Generic profile

## Installation / restoration

1. Back up dynasty saves and close the game completely.
2. Return the installation to clean, stock **Steam FCCD 1.6.5** using the currently installed mod's `RESTORE.bat` before switching mods.
3. Download **one** ZIP below and extract its contents to a separate folder.
4. Run the extracted top-level `INSTALL.bat` and follow its prompts. The Generic installer asks for the desired Large/Medium/Small profile.
5. Run `VERIFY.bat` and confirm the install is verified.
6. Launch the game normally through Steam.
7. To uninstall/switch variants, close the game and run the matching `RESTORE.bat`. Verify stock restoration before installing a different package.

Do not manually combine separate mod folders or apply the standalone Prestige mod on top of these packages. These builds are version-locked to the verified base game.
